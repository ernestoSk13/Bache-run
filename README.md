# Bache Run

Juego de carreras por Torreón donde el rival más peligroso es la calle. Sátira de los problemas de La Laguna.

## Correr

```
npm install
npm run dev
```

Controles: flechas o WASD para manejar, Shift para derrapar, Espacio para usar el objeto. Funciona con mando y con botones táctiles.

## Qué hay

- Pista 1, Bulevar Bachependencia, con 8 pilotos, baches, suspensión, ponchaduras, objetos y recibo de daños.
- Gráficos 3D con Three.js: sombras, cielo, niebla de polvo y fotos reales de Torreón como texturas.

## Documentos

- `docs/PLAN.md`: diseño del juego, pantallas, herramientas y fases.
- `docs/FOTOS.md`: fotos usadas, licencias y cómo se vuelven renderizables.

Parámetros de depuración en la URL: `?auto` (piloto automático), `?speed=10` (acelerar la simulación), `?q=low` (calidad baja).
